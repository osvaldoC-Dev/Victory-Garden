# Victory Garden Café

A [TanStack Start](https://tanstack.com/start) site — TypeScript, React and Tailwind CSS.

## Development

You'll need Node.js (or Bun) installed.

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

The dev server runs on http://localhost:8080.

## Build

```sh
npm run build
npm run preview
```

The production build targets a plain Node.js server by default (the `node-server`
Nitro preset in `vite.config.ts`). If you're deploying to a platform with its own
target — Vercel, Netlify, Cloudflare, etc. — change the `preset` there; see
https://nitro.build/deploy for the full list of presets.
